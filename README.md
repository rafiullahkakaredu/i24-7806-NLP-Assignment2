# i24-7806-NLP-Assignment2

**DS 5007 — Natural Language Processing, Assignment 2: Neural NLP Pipeline (BBC Urdu)**
Rafiullah · i24-7806

**Repository:** https://github.com/rafiullahkakaredu/i24-7806-NLP-Assignment2

Continuation of the Assignment-1 BBC Urdu pipeline. Everything is implemented from scratch in PyTorch:
no pretrained models, no Gensim, no HuggingFace, and no `nn.Transformer` / `nn.MultiheadAttention` / `nn.TransformerEncoder`.

| Part | What is implemented |
|---|---|
| 1 — Word embeddings | TF-IDF term–document matrix (10k vocab + `<UNK>`), PPMI co-occurrence matrix (window 5), t-SNE, Skip-gram Word2Vec with negative sampling (V/U matrices, f(w)^¾ noise table, K=10), nearest neighbours, analogies, 4-condition comparison with MRR |
| 2 — Sequence labelling | Rule-based POS tagger (12 tags, lexicons ≥200 per open class, A1 stemmer/lemmatiser), gazetteer BIO NER, 2-layer BiLSTM (frozen / fine-tuned Word2Vec), CRF + Viterbi, conlleval scoring, ablations A1–A4 |
| 3 — Transformer | Scaled dot-product attention, 4-head self-attention with per-head projections, FFN, sinusoidal PE buffer, 4 Pre-LN blocks, [CLS] + MLP head, AdamW + cosine warm-up, attention heatmaps, BiLSTM vs Transformer comparison |

## Input data

The three Assignment-1 files are required: `cleaned.txt`, `raw.txt`, `Metadata.json`.
The loader auto-detects the document format (`[n]` markers, `====` separators, blank-line blocks or one article per line)
and aligns documents with `Metadata.json` by id or by order. Set `DOC_SPLIT` in cell 0.4 to force a format.

## How to reproduce

### Option A — Google Colab (recommended)
1. Open the notebook in Colab → `Runtime → Change runtime type → T4 GPU`.
2. In the first configuration cell set `SECTION` (the GitHub URL is already filled in).
3. Upload `cleaned.txt`, `raw.txt`, `Metadata.json` to `/content` (or run and use the upload prompt).
4. `Runtime → Run all` (≈10–20 min on a T4). Outputs are written to `/content/i24-7806_Assignment2_DS-X/`
   and zipped; the final cell also builds `report.pdf`.
5. `File → Download → .ipynb` and place it at the root of the zip/repo.

### Option B — local Python
```bash
pip install -r requirements.txt
python scripts/run_all.py --data_dir /path/to/assignment1_files      # add --fast for a 2-minute smoke test
```

### Run a single part
The notebook cells run top-to-bottom; each part depends on objects from the earlier parts
(Part 2 uses the Part-1 Word2Vec embeddings, Part 3 uses the Part-1 vocabulary and topic labels).
- **Part 1:** cells under *Part 1* → `embeddings/*.npy`, `word2idx.json`, t-SNE and loss figures.
- **Part 2:** cells under *Part 2* → `data/*.conll`, `models/bilstm_pos.pt`, `models/bilstm_ner.pt`.
- **Part 3:** cells under *Part 3* → `models/transformer_cls.pt`, confusion matrix, attention heatmaps.
- **Report:** last cell → `results.json`, `report.pdf`, submission zip.
  Rebuild only the report: `python scripts/a2_part4_report.py results.json report.pdf figures`

## Key settings
| | |
|---|---|
| Word2Vec | d=100 (C4: 200), window 5, K=10, Adam 1e-3, batch 1024, 10 epochs, sub-sampling t=1e-4 |
| BiLSTM | 2 layers × 128 per direction, dropout 0.5, Adam 1e-3, weight decay 1e-4, early stopping patience 5 on val F1 |
| Transformer | d_model 128, 4 heads × 32, d_ff 512, 4 Pre-LN blocks, max len 256 + [CLS], AdamW 5e-4 / wd 0.01, cosine + 50 warm-up steps, 20 epochs |
| Seeds | 42 everywhere |

## Notes
- The tag list in the handout contains 11 tags but asks for 12; the 12th tag used is `AUX` (auxiliaries/copula).
- POS/NER gold labels are *silver* labels produced by the rule-based tagger and gazetteer, as the assignment specifies.
- Topic labels for Parts 1/2/3 come from keyword matching (handout keywords + Urdu equivalents) on metadata and body text;
  articles without any keyword are assigned to the nearest TF-IDF category centroid.
